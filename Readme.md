# Шесть городов

**React · TypeScript · React Router · Vite · HTML · CSS**

Учебный проект HTML Academy

Учебный прототип каталога жилья: карточки предложений, страница деталей, представление избранного и форма отзыва.

## Подход к разработке

- **Компонентный подход:** карточки, списки и элементы формы вынесены в отдельные компоненты.
- **Типизация:** предложения описаны TypeScript-типами и передаются через props.
- **Маршрутизация:** страница предложения получает ID из URL и выбирает соответствующие данные.
- **Работа с состоянием:** оценка и текст отзыва управляются через React state.
- **Обработка неизвестного ID:** вместо универсального макета отображается страница «не найдено».

## Технологии

- React 18;
- TypeScript;
- React Router;
- Vite;
- HTML, CSS;
- ESLint;

## Реализованные возможности

- Список карточек из локальных типизированных мок-данных.
- Переход к предложению по ID через название карточки.
- Вывод данных предложения: изображения, цена, тип жилья, вместимость и удобства.
- Экран «не найдено» для неизвестного ID.
- Частичная фильтрация избранного по флагу в мок-данных.
- Локальный ввод текста отзыва и выбор оценки.
- Клиентские маршруты главной, входа, избранного, предложения и страницы «не найдено».

## Структура

```text
src/components/                # общие элементы и компоненты
src/pages/                     # экраны приложения

```

## Локальный запуск

Скачайте исходники, распакуйте их и откройте терминал в корне проекта.

```bash
npm ci
npm start
```

Сборка и локальный просмотр собранного приложения:

```bash
npm run build
npm run preview
```

Проверка исходников линтером:

```bash
npm run lint
```


## Этап реализации

Интерфейс работает с локальными мок-данными. Авторизация, отправка отзыва, изменение избранного, интерактивная карта и серверная интеграция не подключены; выбор города и сортировка представлены на уровне макета.
